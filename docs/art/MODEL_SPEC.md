# 模型規格（Blender → 遊戲）

## 美術方向（2026-10-09 使用者指定）

- **主要參考**：《來自深淵》的**氛圍**——一層層古老地層、失落文明的遺跡被植物吞沒、繩索木棧搭起的探險據點、溫暖手繪感、遺物的神祕感。
  - **版權界線**（CLAUDE.md、GDD 2.5）：只取氛圍，不做它的具體地標、建築外型、服裝、道具，也不描它的圖或拿來當底圖。
- **神話建築**（人類共有文化，可以大方用）：階梯神廟（美索不達米亞）、柱廊（古希臘）、地層石帶——呼應「沉積神話」的世界觀。
- **4X 手遊的畫風**（寒霜啟示錄、王國之歌這類）：Q 版比例、建築頭大、屋頂誇張、暖色、遠看清楚。只借畫風，不照抄素材。
- 配色：灰藍遺跡石、青綠契印、暖金點綴；城內加上灰泥、藍瓦、暖紅屋頂、苔綠。
- **醫館不可以用紅十字**：那是受國際法保護的標誌，改用青綠契印。

# 大地圖模型規格

遊戲已經改成**有模型就用模型、沒有就用灰盒**：做好一個模型，放進指定資料夾、重新打包，地圖上所有同種物件就會換成你的模型。可以一個一個慢慢換，不用一次做完。

---

## 1. 準備

- 安裝 Blender（免費）：在終端機執行 `winget install BlenderFoundation.Blender`，或到 blender.org 下載。
- 模型放這裡：`client/Assets/Resources/Models/World/`
- 檔案格式：`.fbx`（建議）或 `.obj`。

## 2. 共通規則（每個模型都要遵守）

| 項目 | 規則 |
| --- | --- |
| 單位 | **Blender 的 1 公尺 = 地圖上 1 格**。主城佔 2×2 格，就做成大約 2 × 2 公尺。 |
| 原點 | 在**模型底部正中央**，也就是放在地面的那一點（Blender：物件 → 設定原點）。底部要剛好貼在 Z = 0。 |
| 正面 | 朝 Blender **前視圖（數字鍵 1）**看到的那一面。遊戲鏡頭是從南往北、斜上往下看，正面會朝著玩家。 |
| 風格 | 低多邊形（low poly）、色塊為主、輪廓清楚。從斜上方遠看要一眼認得出是什麼。可以參考 Q 版 4X 手遊的比例：建築頭大、屋頂誇張。 |
| 面數 | 主城、深淵入口：3,000 三角面以內。資源田、營地、關隘：1,500 以內。**樹、山（數量很多）：300 以內**。行軍部隊：800 以內。 |
| 材質 | 每個模型 1～4 個材質，只用「基礎色」（Base Color）就好；要貼圖也可以，匯出時嵌入。不要用 Blender 專用的節點效果，遊戲讀不到。 |
| 動畫 | 先不用。 |
| 原創 | 造型與配色要原創。世界觀是「深淵立約（淵契）」：可以有深淵、符文、契約、古老遺跡的元素。**不可以**參考《來自深淵》的角色、造型、地名或畫面。 |

### 匯出設定（檔案 → 匯出 → FBX）

- 限制：只勾「已選取的物件」（先選好要匯出的物件）
- 物件類型：只勾「網格（Mesh）」
- 縮放套用：**FBX 單位縮放（FBX Units Scale）**
- 前方：**-Z 前方（-Z Forward）**；上方：**Y 上方（Y Up）**
- 勾選「**套用變換（Apply Transform）**」
- 勾選「套用修改器（Apply Modifiers）」
- 有貼圖的話：路徑模式選「複製（Copy）」，並按旁邊的「嵌入貼圖」按鈕

## 3. 要做的模型（依建議順序）

檔名要**完全一樣**（大小寫也一樣）。標「可多個變體」的，用 `_A`、`_B`、`_C`… 結尾，遊戲會依位置固定挑一個，看起來比較不單調。

| 順序 | 檔名 | 是什麼 | 大小（格＝公尺） | 備註 |
| --- | --- | --- | --- | --- |
| 1 | `City.fbx` | 領主主城 | 底 2 × 2，高約 2.5 | 地圖上最重要的物件。遊戲會在底下加一圈顏色：金色是自己、紅色是別人，所以模型本身不用分顏色。 |
| 2 | `Tree_A.fbx`、`Tree_B.fbx`… | 樹（可多個變體） | 寬約 1.2，高 1.5～2 | 數量很多，面數一定要低。遊戲會隨機旋轉。 |
| 3 | `Mountain_A.fbx`、`Mountain_B.fbx`… | 分區之間的山脈（可多個變體） | 寬約 5，高 3～6 | 沿著環排一圈，彼此會重疊。高一點的可以有雪頂。會隨機旋轉。 |
| 4 | `Field_Wood.fbx` | 根材田（木頭） | 約 2 × 2，高 ≤ 1.5 | 幾棵樹＋堆好的木材 |
| 5 | `Field_Stone.fbx` | 層岩田（石頭） | 約 2 × 2，高 ≤ 1 | 岩塊、採石場 |
| 6 | `Field_Food.fbx` | 菌糧田（食物） | 約 2 × 2，高 ≤ 0.8 | 菇類田、小棚子 |
| 7 | `Field_Crystal.fbx` | 響晶田（水晶） | 約 2 × 2，高 ≤ 1.5 | 發亮的晶簇（用亮色即可） |
| 8 | `MonsterCamp.fbx` | 怪物營地 | 約 2 × 2，高 ≤ 1.5 | 帳篷、骨頭、破旗，看起來要危險 |
| 9 | `PassTower.fbx` | 關隘兩側的石塔 | 底約 1.5 × 1.5，高約 4 | 關隘兩邊各放一座，正面朝外側 |
| 10 | `AbyssGate.fbx` | 深淵入口 | 約 6 × 6，高約 3 | 崖緣上只有 4 個，可以做得最華麗：通往深淵下一層的門或井 |
| 11 | `Troop.fbx` | 行軍中的部隊 | 約 1 × 1，高約 1 | 3～5 個小兵站一起。遊戲會另外加一面小旗，用顏色表示出征或返回。 |

> 地面、深淵的黑洞、分區的顏色目前還是程式畫的。之後要換成貼圖或模型，再另外訂規格。

## 4. 放進遊戲

1. 把匯出的 `.fbx` 放到 `client/Assets/Resources/Models/World/`。
2. 重新打包客戶端（請 AI 助手打包，或在 Unity 選單執行打包）。在 Unity 編輯器裡按 Play 也能直接看。
3. 開遊戲的大地圖檢查：大小、方向、顏色對不對。
   - 太大或太小：回 Blender 調整尺寸，不要在 Unity 裡縮放。
   - 方向反了：在 Blender 裡把模型繞 Z 軸轉 180 度再匯出。
4. 有問題就截圖給 AI 助手看，它可以調整程式這邊的對齊方式。

## 5. 城內建築（`client/Assets/Resources/Models/City/`）

- **單位**：1 公尺 = 城內 1 格。主堡佔 4 × 4 格，模型寬 3.6 公尺；其他建築佔 3 × 3 格，模型寬 2.7 公尺。原點同樣在底部中央。
- **檔名**：`<建築>_<外觀>.fbx`。外觀 1 = Lv.1～3、2 = Lv.4～6、3 = Lv.7～10。升級跨過門檻，外觀就會變。
  - 建築名：`Keep`、`Sawmill`、`Quarry`、`Farm`、`CrystalMine`、`Warehouse`、`Barracks`、`Hospital`。
  - 例如 `Keep_3.fbx`。
- **未建造的空地基**：`Site.fbx`。
- **限制**：面數 2,000 以內，材質 8 個以內。
- **目前的第一版**由 `tools/blender/generate_city.py` 產生，共 25 個。它沿用 `generate_world.py` 的造型工具和配色。

## 5b. 新版 3D 建築（`client/Assets/Resources/Models/City3D/`，2026-10-09 起優先使用）

- 使用者決定「先用 3D，大地圖上的建築也是，要換回 2D 隨時可以」。照 2D 建築圖（`Resources/Art/Buildings/<Type>_<tier>.png`）在 Blender 建模，第一棟是 `Keep_1`（Codex 用 `tools/blender/keep_1_trial.py` 製作，說明見 `tools/blender/KEEP_1_TRIAL.md`）。
- **規格**：FBX，底面 1×1、原點在底部中心、Y 朝上、正面朝 -Z；4,000～5,000 三角形以內、1 個材質、1 張 1024 albedo（不含光照與高光）；檔名同 2D 圖（`Keep_1.fbx`、`Site.fbx`…）。
- **遊戲裡的順序**：City3D 模型 → 2D 建築圖 → 舊灰盒（`City/`）。有哪棟就換哪棟，其他自動維持 2D。
- 材質在遊戲裡一律換成霧面（`Resources/Abyss/Rock`，保留貼圖）：專案是 Gamma 色彩空間，Standard 的高光會讓整棟發灰。
- 大地圖的主城也用 `City3D/Keep_1`（顯示倍率同舊主城）。
- **換回 2D**：`client/Assets/Scripts/World/ArtSettings.cs` 的 `City3D` 改成 false，或啟動參數加 `-city2d`。
- 2D 建築圖與 2.5D 動態（符文光、炊煙、旗幟擺動）保留不刪；3D 版目前沒有這些動態。

## 6. 程式這邊的對應（給 AI 助手看）

- 載入：`client/Assets/Scripts/World/ModelLibrary.cs`，從 `Resources/Models/<路徑>` 讀檔，找不到就回傳 null，由呼叫端改用灰盒。
- 大地圖：`SurfaceView.cs` 用 `ModelLibrary.Spawn("World/…", 父物件, 位置, S)`，其中 `S = 0.2` 是 1 格的世界單位。
- 2026-10-08 已用一個暫時的測試模型（`Tree.obj`）驗證過整個流程，驗證後已刪除。
- **目前的模型（第一版）由程式產生**：`tools/blender/generate_world.py`（Codex 撰寫，用法見 `tools/blender/README.md`）。在 Blender 背景模式執行，匯出 13 個 FBX（11 種，樹、山各 2 個變體）。風格是灰藍遺跡、青綠契印、暖金點綴。改尺寸或配色就改腳本裡的 `SPECS`／`PALETTE`，重跑即可；想手工精修某個模型，直接用同檔名覆蓋。
- 城內：`CityView.cs` 依等級挑 `City/<Type>_<1~3>`，每格 0.5 世界單位；升級中的鷹架與發光標記仍由程式畫。
- 大地圖顯示倍率：主城 1.5、資源田與營地 1.45、樹 1.25、部隊 1.7、關隘石塔 1.2（`SurfaceView.cs` 常數）。只影響畫面，規則上的佔地不變。
- 地面：`GroundTextures.cs` 在遊戲執行時用雜訊產生草地、乾草、碎石泥地、荒地、廣場的貼圖，不用外部圖檔。
- 遊戲內檢查：打包後用 `-devlogin -server ws://127.0.0.1:5090/ws -artcapture <資料夾>` 啟動（只在本機 Dev 伺服器有效）。它會檢查每個模型的尺寸、貼地、面數、材質，並截圖到該資料夾；結果寫在 log 裡，搜尋 `ART_CHECK`。程式在 `client/Assets/Scripts/World/WorldModelCapture.cs`。
