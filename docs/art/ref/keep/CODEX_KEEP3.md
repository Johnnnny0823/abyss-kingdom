# Codex 派工：重建主堡 Keep_3（Lv.7～10）

## 目標

用這個資料夾的參考圖重做 `client/Assets/Resources/Models/City3D/Keep_3.fbx`（加 `Keep_3_Albedo.png`）。現在的版本是只照一張斜角圖做的，背面和側面是猜的。這次要讓**各面都有依據，平面配置照 `keep_plan.svg`**。

## 高度（Keep_3 總高 1.60，`generate_city3d.py` 的 HEIGHTS 不變）

石基約 0.12；外牆頂約 0.45；角塔尖頂約 0.85（旗桿另計）；主塔牆頂約 0.95、屋脊約 1.40；主塔旗桿頂 1.60。

## 規格與必須保留的東西

- 照 `docs/art/MODEL_SPEC.md` 5b 和 `tools/blender/CITY3D_BATCH.md`：FBX、底面 1×1、原點在底部中心、Y 朝上、正面 -Z、1 個材質、1 張 1024 albedo（不含光影），發光部位用保留色 `B8FFF1`／`37BCAE`／`F6B647`。
- 三角形預算：**5,000 以內**（使用者若另外指定更高，以使用者為準）。
- 照 `tools/blender/BUILDING_POLISH.md` 保留：`BuildingBody` 網格、`FlagCloth_*` 旗布（vertex color R：固定邊 0 → 自由端 1）、`SmokeSocket_00` 煙口。
- 只動 Keep_3。不要改 Keep_1、Keep_2、其他建築、`client/Assets/Scripts`、原始 2D 圖。

## 驗收

1. 用 `verify_city3d.py`（或對應的 polish 驗證）驗證匯出的 FBX，通過；更新 manifest。
2. 輸出 5 張預覽：遊戲斜角（仰角 52°、方位 -32°）、正面、背面、左側、右側，放 `artifacts/keep3_rebuild/`。
3. 自查：外圍塔數 5、拱廊只在右側、樓梯只在正面、後牆沒有大門、主塔偏左後。
4. 交接說明寫在 `tools/blender/KEEP_3_REBUILD.md`：怎麼重跑、三角形數、和舊版的差異。不要啟動 Unity，實機檢查交給 Claude。
