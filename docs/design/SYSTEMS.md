## 1. 主將（主打角色）

主將是玩家的核心養成對象：**帶兵出征**、**打遠征**、**穿裝備與造型**。

### 出征目標

主將帶領部隊（沉錨衛／鳴弦手／懸索騎）出征，地圖上的目標：

| 目標 | 說明 | 階段 |
| --- | --- | --- |
| 其他玩家的領地 | PvP 攻城；戰敗傷兵進醫院（低懲罰，已定案） | 第 10–11 週 |
| 資源點 | 採集，可被別人搶 | 第 5–7 週 |
| 深淵小怪 | 單隊可打，日常材料 | 第 5–7 週 |
| 中 BOSS（守層者） | 集結，突破材料 | 地圖之後 |
| 世界 BOSS | 全服／聯盟賽季事件 | 聯盟之後 |
| 地區、世界之森 | 聯盟占領 | 聯盟之後 |

### 主將屬性

- **品質**：沿用已定案的「繩級」：綠 → 藍 → 紫 → 金 → 黑。
- **統率**：決定一支行軍能帶多少兵，是主將和部隊系統的連結點。
- **兵種專精**：每位主將擅長一種兵種，帶對應兵種時有加成。三兵種克制已定案：沉錨衛 → 懸索騎 → 鳴弦手 → 沉錨衛。
- **技能**：主動 1 個＋被動 2 個；境界突破時解鎖或強化。
- **裝備**：6 格（武器、頭、身、手、飾品、遺物）；遠征掉落為主。
- **造型**：外觀；部分造型附帶小幅屬性（見商城的「差異化原則」）。
- **古神殘念**（★★★ 概念，參考自「旁觀者贊助」）：主將可以和一位沉沒古神的殘念「結契」，獲得一個專屬技能與一串契約任務。換契有冷卻。

## 2. 境界：四境與獨響之道（主將成長的主線）

> 2026-10-08 依使用者說明改版：取《看臉時代》「四項能力的掌握程度決定強弱層級，之上是只屬於自己的道路」這個**結構概念**；名稱、招式、表現全部原創。

### 四境

每位主將有四條能力線，各自修練到「通達」：

| 境 | 名稱 | 戰鬥效果 | 大地圖效果 |
| --- | --- | --- | --- |
| 力 | **震境** | 傷害、破防 | 攻城、打野傷害 |
| 技 | **巧境** | 暴擊、技能倍率，降低被兵種克制的懲罰 | 採集效率 |
| 速 | **迅境** | 出手順序、迴避 | 行軍速度 |
| 韌 | **磐境** | 生命、減傷、戰敗時傷兵比例降低 | 防守、駐守 |

### 層級：通達幾境決定你站在哪裡

| 通達數 | 層級 | 說明 |
| --- | --- | --- |
| 0–1 | 凡身 | 新手 |
| 2 | **雙極** | 很基本，多數主將的常態 |
| 3 | **三極** | 很強，伺服器中的高手 |
| 4 | **圓極**（頂點） | 四境皆通，解鎖「忘我境」：低血量時進入爆發狀態 |
| 圓極之上 | **獨響之道** | 只屬於你的道路，見下節 |

- **怎麼修練——「你怎麼打，就長成什麼樣」**（2026-10-08 使用者定案：**表現為主、材料為輔**）：每場遠征、迴廊、地圖戰鬥結束後，伺服器依主將的實際表現發放各境的修練值：打出高傷害累積震境，暴擊與技能命中累積巧境，搶先出手與迴避累積迅境，扛傷害並活下來累積磐境。此外也能用材料定向補強，讓玩家不會卡關。
- **通達試煉**：每一境的修練值滿了，要打贏該境的「夢魘試煉」才算通達。試煉考的是該境的特性：震境要在時限內打破護盾，迅境要搶在敵人蓄力前出手。
- **勤修**：離線時也會累積修練值（上限 12 小時），由玩家指定要修哪一境。

### 獨響之道：開創或同行

圓極之後，主將可以「鑄道」。道路由四個要素組成：

1. **四境的通達順序**：例如「磐 → 震 → 迅 → 巧」，從遊玩過程中自然形成，共 24 種。
2. **主修之境**：四境中修得最深的那一境，決定絕技的主軸。
3. **古神殘念**：締結契約的沉沒古神，決定絕技的回響屬性，例如潮、燼、霜、秤、蝕。
4. **殘響印記**：在無盡迴廊留下的最深印記，決定絕技的附加效果。

**道路規則**（2026-10-08 使用者定案）：

- **開創者**：第一位鑄出某種組合的玩家，就是這條道路的開創者，名字永久記在「道路名冊」上。
- **同行或開創，由玩家自己選**：如果你的組合已經有人走過，系統會告訴你「這條路由〇〇開創，目前有 N 人同行」，並提供兩個選項：
  - **同行**：直接走這條道路，**熱門道路照樣可以選**。
  - **開創**：系統列出幾個「只差一步」的未開創組合，例如「改締霜之古神」「刻下第 45 層印記」，並說明下一步要做什麼。完成後，你就是新道路的開創者。
- **名冊的歷史感**：每條道路可以看到開創者、開創日期、同行人數，以及這條道路上的最強者。
- **組合會持續增加**：每新增一位古神或一種印記，可走的道路數量就倍增。
- **重鑄**：之後想反悔，可以像重置技能樹一樣「重鑄」，返還投入的點數和材料，重新選擇道路。重鑄需要「重鑄石」（魔晶石可買，首次免費），並有冷卻時間，避免在戰鬥前隨意切換。重鑄後，原本的開創者頭銜**保留在名冊上**，歷史不會被抹掉。

**專屬絕技**：鑄道時，伺服器依四個要素組裝出絕技。

- 形態由主修之境決定：震境是單點重擊，巧境是連段，迅境是瞬步突襲，磐境是反擊領域。
- 屬性和附加效果由古神與印記決定。
- **絕技名稱由開創者命名**（會經過不當字詞過濾）。同行者使用同一招，戰報上顯示「〇〇（開創：某某）」，開創者的名字會跟著絕技流傳。
- 開創者只有榮譽，沒有額外數值：名冊留名、絕技冠名、專屬稱號與外框。同行者不會比開創者弱。

- **賽季稱號**：每個賽季統計鑄道者的戰績，排名前段的獲得「第 N 紀元之王」，下一季可以展示。這部分參考了世代王者的概念。

## 3. 遠征（PvE 主線，主將養成來源）

- **結構**：每個地層一章，每章 10–20 關，關卡對應該層的魔物與守層者。
- **戰鬥**：主將＋最多 4 名副將組隊，自動戰鬥。由伺服器用固定種子跑確定性模擬，再把戰報下發；客戶端只播放戰報，防作弊。這套模擬和之後的大地圖戰鬥共用同一套戰鬥核心（第 8–9 週）。
- **掉落**：裝備、突破材料、資源、加速道具、魔晶石（少量）。
- **掛機收益**：已通關的最高關會持續產出資源和經驗，參考王國之歌的做法。
- **解鎖無盡迴廊**：通關第一章後，劇情發現「無盡迴廊」。

## 4. 無盡迴廊（無限深淵迷宮）

- **類型**：Roguelike 爬層。每層由伺服器種子生成，房間有戰鬥、事件、商人、休息、寶箱。
- **遺物**：一次挑戰內有效的強化，例如「鳴弦手攻擊 +20%」。
- **殘響印記**（★★★ 概念，參考自「反覆死亡、靠堅持變強」）：每次倒下會依到達樓層留下印記，下次挑戰有永久小幅加成，上限遞減。用意是讓「肯努力的人」也能爬上去，不只「肯花錢的人」。
- **重置與排行**：每週重置，全服排行，依最高樓層發獎。
- **怪談樓層**：偶爾出現規則型樓層，例如「這層不能回頭」「不可回應呼喚」，違反規則就觸發特殊敵人。

## 5. 商城與貨幣

### 兩種貨幣

| 貨幣 | 取得 | 用途 |
| --- | --- | --- |
| **魔晶石** | 遊戲內（任務、遠征、活動、成就），或用課金貨幣兌換 | 大多數物品：加速、資源包、招募、一般造型、背包擴充 |
| **淵心鑽** | 只能儲值取得 | 單向兌換成魔晶石；課金限定商品：高級造型、月卡、通行證高級版、特殊活動主城樣式、高級裝備箱 |

- **兌換只能單向**：淵心鑽可以換魔晶石，魔晶石不能換回淵心鑽。
- **同一件物品分兩個版本**（使用者要求的「相同物品有區別」）：例如主將造型「霜冠」有魔晶石版（靜態外觀）和淵心鑽版「血契・霜冠」（動態特效、專屬出征動畫、回城特效、名牌外框）。

### 差異化原則（我的建議，請你決定）

SLG 本來就有一定程度的付費優勢，但「課金版直接強很多」最容易讓非課金玩家流失，伺服器一空，課金玩家也沒人可打。建議：

1. 課金版的差異以**外觀、特效、便利性**為主，例如自動化、額外隊列、背包空間。
2. 若要附帶屬性，**課金版和魔晶石版的屬性差距設上限**，例如造型屬性最多差 2%。
3. 真正的強度差距來自**時間**：花錢可以「更快」拿到，但免費玩家「一定拿得到」。

**2026-10-08 使用者決定**：暫時採用上面的原則（屬性差距上限 2%），但擔心課金大佬玩得不夠爽。

### 讓課金大佬爽，又不靠數值碾壓

SLG 大佬想要的主要是「**被看見**」和「**帶領別人**」，不只是數字比較大：

| 類型 | 做法 |
| --- | --- |
| **快** | 時間就是大佬的優勢：更多加速、額外建築隊列、自動採集，同樣的目標早幾週達成，領先感很強 |
| **被看見** | 全服公告（「〇〇 領主開啟了傳說寶庫」）、主城外觀與出征特效、名牌外框、地圖上的專屬城堡造型、聊天框樣式 |
| **身分等級** | 累積儲值的「淵主等級」，一級一個稱號，最高等級全服可見；每級解鎖便利功能（例如一鍵收取、更多預設編隊） |
| **帶領聯盟** | 大佬購買禮包時，全聯盟成員都會收到一份「聯盟禮物」（王國之歌、寒霜啟示錄的核心做法）。盟友會感謝大佬，大佬會很有面子 |
| **收藏與炫耀** | 限定造型、限定主城、限定絕技特效；每個賽季的限定品，過季就買不到 |
| **榜單** | 戰力榜、迴廊榜、世界 BOSS 傷害榜，前段發限定外觀 |
| **可調的數值空間** | 如果之後封測覺得大佬不夠爽，**第一個放寬的是「上限 2%」這個數字**（例如放寬到 5%），不用改整個架構 |

### 法規與平台（上線前必須處理）

- **機率公開**：英雄招募這類隨機付費商品，台灣規定要公開機率。韓國、日本、中國也有類似規定。
- **Steam**：遊戲內購買必須走 Steam 錢包（Steamworks 微交易 API），自架網站版可另接金流。
- **訂單冪等**（已定案）：同一筆資料庫交易內完成「驗收據 → 寫訂單 → 發貨」，用訂單號防止重複發貨。

## 6. 建議的實作順序（取代 HANDOFF 第 7 節第 6 項以後）

遠征不需要大地圖，可以先做；而且做遠征就順便把「戰鬥核心」做出來，大地圖會直接用到。

1. **主將基礎**：主將資料、品質、統率、等級，加上 3 位初始主將（不做抽卡）。
2. **戰鬥核心**：確定性自動戰鬥（定點數、伺服器結算、戰報）＋三兵種克制。
3. **遠征第一章**：10 關、掉落、掛機收益。
4. **四境修練＋通達試煉**（先做到雙極）；獨響之道放在圓極玩家出現之後。
5. **大地圖第 1 層**：行軍、資源點、小怪、守層者，用上主將＋戰鬥核心。
6. **無盡迴廊**（基礎版）。
7. **商城與貨幣**：先做魔晶石商店；淵心鑽等到有金流再做（Steam 上架時）。
8. 聯盟、世界之森、世界 BOSS、攻城。
