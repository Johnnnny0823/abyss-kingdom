## 1. 主將（主打角色）

主將是玩家的核心養成對象：**帶兵出征**、**打遠征**、**穿裝備與造型**。

### 出征目標

主將帶領部隊（沉錨衛／鳴弦手／懸索騎）出征，地圖上的目標：

| 目標 | 說明 | 階段 |
| --- | --- | --- |
| 其他玩家的領地 | PvP 攻城；戰敗傷兵進醫院（低懲罰，已定案） | 第 10–11 週 |
| 資源點 | 採集，可被別人搶 | 第 5–7 週 |
| 深淵小怪 | 單隊可打，日常材料 | 第 5–7 週 |
| 中 BOSS（守層者） | 集結，突破材料 | 地圖之後 |
| 世界 BOSS | 全服／聯盟賽季事件 | 聯盟之後 |
| 地區、世界之森 | 聯盟占領 | 聯盟之後 |

### 主將屬性

- **品質**：沿用已定案的「繩級」：綠 → 藍 → 紫 → 金 → 黑。
- **統率**：決定一支行軍能帶多少兵，是主將和部隊系統的連結點。
- **兵種專精**：每位主將擅長一種兵種，帶對應兵種時有加成。三兵種克制已定案：沉錨衛 → 懸索騎 → 鳴弦手 → 沉錨衛。
- **技能**：主動 1 個＋被動 2 個；境界突破時解鎖或強化。
- **裝備**：6 格（武器、頭、身、手、飾品、遺物）；遠征掉落為主。
- **造型**：外觀；部分造型附帶小幅屬性（見商城的「差異化原則」）。
- **古神殘念**（★★★ 概念，參考自「旁觀者贊助」）：主將可以和一位沉沒古神的殘念「結契」，獲得一個專屬技能與一串契約任務。換契有冷卻。

## 2. 境界（主將成長的主線）

參考方向是「世代層級」與「極限狀態」。《看臉時代》官方沒有境界系統，以下是原創設計。

**9 個境界，分 3 階；每跨一階都要通過「夢魘試煉」。**

| 階 | 境界 | 意義 |
| --- | --- | --- |
| 凡鳴 | 1 拾響 → 2 調響 → 3 共響 | 學會聽見深淵的回響 |
| ── 第一道夢魘試煉 ── | | |
| 深鳴 | 4 沉響 → 5 渦響 → 6 逆響 | 能承受、操控回響 |
| ── 第二道夢魘試煉 ── | | |
| 無鳴 | 7 寂響 → 8 歸源 → 9 無名 | 與原初混沌同調 |

- **同境界內**：用經驗與「響石」升級。
- **突破**：需要遠征掉落的突破材料，並打贏一場單人試煉戰。試煉會刻意設計成「懂機制就能贏」，而不是「數值夠才能贏」。
- **忘我境**：主將血量低於 30% 時，有機率進入幾秒的爆發狀態。境界越高，觸發率越高、持續越久。這是戰鬥中的高潮時刻。
- **勤修**：主將離線時也會累積修練值，上限 12 小時，登入時領取（掛機收益）。
- **賽季稱號**：賽季結束時，最高境界與戰力排名前段的玩家獲得「第 N 紀元之王」稱號，下個賽季可展示。

## 3. 遠征（PvE 主線，主將養成來源）

- **結構**：每個地層一章，每章 10–20 關，關卡對應該層的魔物與守層者。
- **戰鬥**：主將＋最多 4 名副將組隊，自動戰鬥。由伺服器用固定種子跑確定性模擬，再把戰報下發；客戶端只播放戰報，防作弊。這套模擬和之後的大地圖戰鬥共用同一套戰鬥核心（第 8–9 週）。
- **掉落**：裝備、突破材料、資源、加速道具、魔晶石（少量）。
- **掛機收益**：已通關的最高關會持續產出資源和經驗，參考王國之歌的做法。
- **解鎖無盡迴廊**：通關第一章後，劇情發現「無盡迴廊」。

## 4. 無盡迴廊（無限深淵迷宮）

- **類型**：Roguelike 爬層。每層由伺服器種子生成，房間有戰鬥、事件、商人、休息、寶箱。
- **遺物**：一次挑戰內有效的強化，例如「鳴弦手攻擊 +20%」。
- **殘響印記**（★★★ 概念，參考自「反覆死亡、靠堅持變強」）：每次倒下會依到達樓層留下印記，下次挑戰有永久小幅加成，上限遞減。用意是讓「肯努力的人」也能爬上去，不只「肯花錢的人」。
- **重置與排行**：每週重置，全服排行，依最高樓層發獎。
- **怪談樓層**：偶爾出現規則型樓層，例如「這層不能回頭」「不可回應呼喚」，違反規則就觸發特殊敵人。

## 5. 商城與貨幣

### 兩種貨幣

| 貨幣 | 取得 | 用途 |
| --- | --- | --- |
| **魔晶石** | 遊戲內（任務、遠征、活動、成就），或用課金貨幣兌換 | 大多數物品：加速、資源包、招募、一般造型、背包擴充 |
| **龍血鑽**（名稱待定） | 只能儲值取得 | 單向兌換成魔晶石；課金限定商品：高級造型、月卡、通行證高級版、特殊活動主城樣式、高級裝備箱 |

- **兌換只能單向**：龍血鑽可以換魔晶石，魔晶石不能換回龍血鑽。
- **同一件物品分兩個版本**（使用者要求的「相同物品有區別」）：例如主將造型「霜冠」有魔晶石版（靜態外觀）和龍血鑽版「血契・霜冠」（動態特效、專屬出征動畫、回城特效、名牌外框）。

### 差異化原則（我的建議，請你決定）

SLG 本來就有一定程度的付費優勢，但「課金版直接強很多」最容易讓非課金玩家流失，伺服器一空，課金玩家也沒人可打。建議：

1. 課金版的差異以**外觀、特效、便利性**為主，例如自動化、額外隊列、背包空間。
2. 若要附帶屬性，**課金版和魔晶石版的屬性差距設上限**，例如造型屬性最多差 2%。
3. 真正的強度差距來自**時間**：花錢可以「更快」拿到，但免費玩家「一定拿得到」。

### 法規與平台（上線前必須處理）

- **機率公開**：英雄招募這類隨機付費商品，台灣規定要公開機率。韓國、日本、中國也有類似規定。
- **Steam**：遊戲內購買必須走 Steam 錢包（Steamworks 微交易 API），自架網站版可另接金流。
- **訂單冪等**（已定案）：同一筆資料庫交易內完成「驗收據 → 寫訂單 → 發貨」，用訂單號防止重複發貨。

## 6. 建議的實作順序（取代 HANDOFF 第 7 節第 6 項以後）

遠征不需要大地圖，可以先做；而且做遠征就順便把「戰鬥核心」做出來，大地圖會直接用到。

1. **主將基礎**：主將資料、品質、統率、等級，加上 3 位初始主將（不做抽卡）。
2. **戰鬥核心**：確定性自動戰鬥（定點數、伺服器結算、戰報）＋三兵種克制。
3. **遠征第一章**：10 關、掉落、掛機收益。
4. **境界 1～3** 加第一道夢魘試煉。
5. **大地圖第 1 層**：行軍、資源點、小怪、守層者，用上主將＋戰鬥核心。
6. **無盡迴廊**（基礎版）。
7. **商城與貨幣**：先做魔晶石商店；龍血鑽等到有金流再做（Steam 上架時）。
8. 聯盟、世界之森、世界 BOSS、攻城。
